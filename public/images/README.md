# 📸 Photos Folder

Place your best friend's photos in this folder!

### How to use your photos:
1. Save your photos here (e.g. `photo1.jpg`, `photo2.jpg`, `photo3.jpg`).
2. Open `src/config/birthdayData.js`.
3. In the `memories` array, update the `image` path:
   ```javascript
   {
     id: 1,
     image: "/images/photo1.jpg",
     caption: "Our favorite trip! 🏖️",
     date: "Summer 2024",
     location: "Goa",
     rotation: -3,
     tag: "Best Day",
   }
   ```
4. You can also upload photos directly inside the website using the "Add Another Photo 📷" button!
